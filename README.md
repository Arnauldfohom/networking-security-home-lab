**Networking & Security Home Lab**

**Overview**

This repository documents my hands-on journey into computer networking and cybersecurity through a 10-day home lab challenge.

The project focuses on practical experimentation, network analysis, troubleshooting, security fundamentals, and technical documentation.

My goal is to strengthen my understanding of network infrastructure and defensive security while building a portfolio of practical, reproducible technical work.


**Objectives**

Understand fundamental networking concepts and protocols.

Investigate connectivity and troubleshoot network issues.

Capture and analyze network traffic.

Explore network services, ports, and firewall behavior.

Practice basic security assessment techniques in an authorized lab.

Document findings using professional technical reports.

Develop a foundation for future cybersecurity and automation projects.

**Security and Ethics**

All experiments are performed on systems I own or am explicitly authorized to test.

Sensitive information, credentials, personal data, and unapproved traffic captures will not be published.

Security findings will be documented responsibly and within the scope of the lab.


**Final Goal**

By the end of this challenge, this repository will contain a structured collection of practical lab reports, supporting evidence, technical observations, troubleshooting notes, and a final mini security audit.

The project will serve as a foundation for continued learning in networking, cybersecurity, and security automation.
